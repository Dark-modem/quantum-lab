# Traffic overhead results — 2026-11-06 (phase 3: matrix + frp)

Both engines measured between the same two servers (iran amd64 ↔ germany
arm64) with the same method (nftables carrier counters, pre/post deltas
around each run, 3 reps). Matrix numbers reference the 2026-11-05
late-night window (`results/overhead-2026-11-05.md`); frp numbers come
from the 2026-11-05 evening window (~22:00–01:00 UTC+3:30) — the only
window where the FRP deployment was live. Cross-window comparison of
RATIOS is valid (rate-independent); throughputs are window-dependent.

## Engine: frp (frps on germany, frpc on iran; TCP mux on port 7000)

| direction | workload | wire/payload (germany view) | throughput | n |
|---|---|---|---|---|
| down | tcp_bulk | **0.967 / 1.031 / 1.002** | 8.5 → 145 → 122 Mb/s | 3/3 |
| up | tcp_bulk | 2.42 / 1.69 (evening uplink ~1 Mb/s — unreliable, see note) | 0.7–1.0 Mb/s | 3/3 |
| down | udp s64–s1400 | UNVERIFIED (harness run died mid-pass; rows lost) | — | 0/3 |

**Headline: frp's bulk-TCP overhead is ≈ 0–3 %** — essentially raw TCP
(frp's mux adds only tiny framing over one established connection). The
up-direction numbers are not overhead: at ~1 Mb/s evening uplink the
window skews and the ACK direction dominates the summed counters.
The germany view counts the tunnel leg (tcp/7000) on the host that
carries it — the correct wire view for frp (the iran-side post-samples
were lost to a harness defect, noted below; the germany view alone is
authoritative for this engine since the whole tunnel leg traverses it).

## Comparison (bulk TCP, wire/payload)

| engine | up | down |
|---|---|---|
| frp | ~1.00–1.03 (night window would be cleaner; evening uplink distorted) | **1.00–1.03** |
| matrix/tinc | 1.126 | 1.333 |

frp is the leaner encapsulation (user-space TCP mux, no per-packet IP
header duplication); tinc carries full inner IP packets + encryption.
For the panel's coefficient feature: `coefficient ≈ datacenter price
ratio × measured overhead` — frp ≈ 1.03, matrix ≈ 1.13–1.33 depending on
direction, on tonight's path.
